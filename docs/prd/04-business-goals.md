# 04 — Business Goals

## Tujuan Bisnis

### Model Bisnis

RPS OBE adalah produk **SaaS (Software as a Service)** dengan model langganan tahunan (*annual subscription*).

### Target Pelanggan

| Kategori | Jumlah di Indonesia | Target Penetrasi (5 tahun) |
|----------|---------------------|----------------------------|
| Universitas | ~500 | 30% (150) |
| Institut | ~200 | 25% (50) |
| Politeknik | ~300 | 20% (60) |
| Sekolah Tinggi | ~2.000 | 10% (200) |
| Akademi | ~1.000 | 5% (50) |
| **Total** | **~4.000** | **~510 institusi** |

### Paket Langganan

| Paket | Harga (per tahun) | Fitur |
|-------|-------------------|-------|
| Basic | Rp 5.000.000 | 3 prodi, RPS Builder, Export, Workflow |
| Professional | Rp 15.000.000 | 10 prodi, AI Assistant, AI Validator |
| Enterprise | Rp 50.000.000 | Unlimited prodi, Multi-fakultas, AI Reviewer, Template kustom, API |
| Custom | Negosiasi | Multi-kampus, SSO, Dedicated server, White label |

### Proyeksi Pendapatan

| Tahun | Institusi | ARPU/tahun | Pendapatan |
|-------|-----------|------------|------------|
| 2026-2027 | 50 | Rp 12.000.000 | Rp 600.000.000 |
| 2027-2028 | 150 | Rp 12.000.000 | Rp 1.800.000.000 |
| 2028-2029 | 300 | Rp 14.000.000 | Rp 4.200.000.000 |
| 2029-2030 | 500 | Rp 14.000.000 | Rp 7.000.000.000 |

### Strategi Akuisisi

| Kanal | Strategi |
|-------|----------|
| Konferensi | APTISI, Forum Rektor, Seminar Akreditasi |
| Partnership | LLDikti, BAN-PT, LAM |
| Digital | LinkedIn, Google Ads, Komunitas Dosen |
| Referral | Program afiliasi antar perguruan tinggi |
| Freemium | Free trial 30 hari untuk 1 prodi |

### Key Business Metrics

| Metrik | Target |
|--------|--------|
| Customer Acquisition Cost (CAC) | < Rp 3.000.000 |
| Customer Lifetime Value (LTV) | > Rp 36.000.000 (3 tahun) |
| LTV:CAC Ratio | > 12:1 |
| Churn Rate | < 10% per tahun |
| Net Revenue Retention (NRR) | > 110% |
| Time to Value (TTV) | < 7 hari |
| NPS (Net Promoter Score) | > 50 |

### Strategi Monetisasi Tambahan

| Produk | Estimasi Kontribusi |
|--------|---------------------|
| Langganan SaaS | 80% |
| Pelatihan & Sertifikasi | 10% |
| Konsultasi Kurikulum OBE | 5% |
| Custom Development | 3% |
| API Access Tier | 2% |

### Analisis Kompetitor

| Kompetitor | Kekuatan | Kelemahan |
|------------|----------|-----------|
| SISTER (Kemdikbud) | Gratis, wajib | Tidak OBE-focused, tidak ada AI |
| Google Docs / Word | Familiar | Tidak terstruktur, tidak ada validasi |
| LMS (Moodle, Canvas) | Banyak digunakan | Fokus delivery, bukan perencanaan |
| Custom Excel | Fleksibel | Error-prone, tidak collaborative |
