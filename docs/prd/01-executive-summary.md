# 01 — Executive Summary

## Ringkasan Eksekutif

RPS OBE adalah platform SaaS berbasis web yang dirancang untuk membantu perguruan tinggi di Indonesia dalam menyusun, memvalidasi, mereview, mengelola, dan mempublikasikan Rencana Pembelajaran Semester (RPS) berbasis Outcome Based Education (OBE). Platform ini menjawab kebutuhan mendesak perguruan tinggi untuk beradaptasi dengan standar akreditasi nasional (BAN-PT, LAM) dan internasional yang mensyaratkan pendekatan OBE dalam kurikulum.

## Latar Belakang

Peraturan Menteri Pendidikan dan Kebudayaan mewajibkan setiap perguruan tinggi menyusun RPS untuk setiap mata kuliah. Dalam praktiknya, penyusunan RPS berbasis OBE menghadapi tantangan besar:

1. **Kompleksitas Pemetaan** — CPL, CPMK, Sub-CPMK harus selaras (Constructive Alignment)
2. **Inkonsistensi Format** — Antar dosen dan program studi sering berbeda format
3. **Validasi Manual** — Tidak ada mekanisme otomatis untuk memvalidasi keselarasan
4. **Kolaborasi Terbatas** — Review dan approval masih dilakukan secara manual via email/WhatsApp
5. **Jejak Audit Minim** — Tidak ada versioning dan audit trail yang memadai

## Solusi

RPS OBE menyediakan solusi end-to-end:

- **RPS Builder** berbasis wizard untuk menyusun RPS langkah demi langkah
- **AI Assistant** untuk membantu menghasilkan CPMK, Sub-CPMK, materi, assessment, dan referensi
- **AI Validator** untuk memeriksa constructive alignment, taksonomi Bloom, bobot nilai, dan konsistensi
- **Workflow Review & Approval** terstruktur dari Draft hingga Published
- **Multi-kampus** — satu platform untuk seluruh universitas, fakultas, dan program studi
- **Export** ke Word dan PDF dengan template kustom

## Target Pasar

Platform menargetkan lebih dari 4.500 perguruan tinggi di Indonesia, mencakup universitas, institut, politeknik, sekolah tinggi, dan akademi — baik negeri maupun swasta.

## Model Bisnis

SaaS (Software as a Service) dengan model langganan berbasis jumlah program studi dan/atau jumlah pengguna aktif per kampus.

## Manfaat Utama

| Manfaat | Deskripsi |
|---------|-----------|
| Efisiensi Waktu | Penyusunan RPS 70% lebih cepat |
| Kualitas | AI Validator memastikan constructive alignment |
| Standarisasi | Format seragam di seluruh institusi |
| Kolaborasi | Workflow review dan approval terintegrasi |
| Akreditasi | Dokumen siap untuk keperluan BAN-PT dan LAM |
| Audit Trail | Versioning dan log aktivitas lengkap |

## Tiga Pilar Produk

1. **Builder** — Membangun RPS dengan wizard yang intuitif
2. **AI Engine** — Asisten dan validator berbasis kecerdasan buatan
3. **Workflow** — Siklus hidup RPS dari draft hingga publikasi
