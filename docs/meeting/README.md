# Catatan Rapat

Direktori ini menyimpan seluruh catatan rapat terkait pengembangan proyek RPS OBE. Setiap catatan rapat disimpan sebagai file terpisah dengan format penamaan `YYYY-MM-DD-<topik-singkat>.md` untuk memudahkan pencarian dan pengurutan kronologis.

## Tujuan

- Mendokumentasikan seluruh diskusi, keputusan, dan hasil rapat selama siklus hidup proyek
- Menyediakan referensi historis untuk melacak evolusi keputusan dan perubahan requirement
- Memastikan akuntabilitas melalui pencatatan action items dan penanggung jawab yang jelas
- Memfasilitasi onboarding anggota tim baru dengan menyediakan konteks historis keputusan proyek

## Pedoman Pencatatan

1. **Tulis segera setelah rapat** — Jangan menunda lebih dari 24 jam untuk memastikan akurasi.
2. **Gunakan kalimat pendek dan jelas** — Hindari paragraf panjang. Gunakan bullet points.
3. **Jangan mencatat diskusi kata per kata** — Fokus pada poin utama, argumen kunci, dan keputusan.
4. **Sertakan konteks** — Pembaca di masa depan mungkin tidak hadir di rapat. Berikan konteks yang cukup.
5. **Periksa action items** — Pastikan setiap item memiliki penanggung jawab dan tenggat yang jelas.
6. **Gunakan nama lengkap** — Jangan gunakan inisial. Gunakan nama lengkap untuk seluruh peserta.
7. **Tandai keputusan dengan jelas** — Gunakan kata kunci "DISETUJUI", "DITOLAK", atau "DITUNDA" pada setiap keputusan.
8. **Simpan file di direktori ini** — Jangan simpan di folder lain atau di aplikasi chat.
